# База рекламных интеграций

Реестр: `registry.json`, исходники: `media/`.

Типы:
- **banner** — висит весь клип (зациклен, без звука, без прерывания видео).
- **midroll** — вставка один раз (или по расписанию) с остановкой кадра и со звуком.

| ID | Бренд | Тип | Файл | Правила |
|---|---|---|---|---|
| natria_vpn | NATRIA VPN | midroll, 7.2 с, озвучка | natria_vpn_midroll.mp4 | ровно по центру экрана, ≥25% площади; ролик < 2:00 — 1 раз ровно в середине; ≥ 2:00 — на 0:30 и 1:30; ускорение ≤ 1.3x; озвучка хорошо слышна |
| playerok_banner | PLAYEROK | banner, 12.25 с, без звука (версия GTA6, 01.11–30.11) | playerok_banner_gta6.mov | весь ролик, зациклен, ≥1/6 экрана, в активной зоне, не затемнять/не обрезать/не скрывать интерфейсом; для роликов до 12 с или без озвучки |
| playerok_midroll | PLAYEROK | midroll, 3.2 с, озвучка | playerok_midroll.mp4 | позиция строго как в шаблоне (1:1 на 1080x1920); поверх стоп-кадра, звук видео остановлен; не затемнять/не ускорять; ролик < 20 с — в любой момент, кроме последних 3 с; ≥ 20 с — старт на 10–20 с (±1), кроме последних 3 с; для роликов от 12 с |
| bigballs | BIG BALLS | midroll, 4.1 с, озвучка; эксклюзив | bigballs_midroll.mp4 | строго по центру, ≥30% экрана; не раньше 10-й с (ролик < 10 с — посередине); повтор каждую минуту, если до конца ≥ 1 мин; пауза основного видео; ускорение ≤ 1.2x; без рекламы/упоминаний других проектов; не принимают накрутку, промо, слайдшоу, Reddit-истории, фильмы/сериалы |

Инструменты:
- `python3 tools/clipper.py job.json` — сборка клипа (раскладка, субтитры, баннер, мидролл, серии).
- `python3 tools/ads.py <clip.mp4> <ad_id> <out.mp4>` — вставить мидролл в готовый ролик.

Раскладки (1080x1920):
- `plain` (без баннера): вебка 620 · субтитры 140 · геймплей 840 · нижняя зона 320 (хук, «ЧАСТЬ N/M»).
- `banner` (с баннером ≥1/6): вебка 440 · субтитры 110 · геймплей 810 · зона баннера 560 (баннер ≈17.1% экрана).
