# База рекламных интеграций

Реестр: `registry.json`, исходники: `media/`.

Типы:
- **banner** — висит весь клип (без прерывания видео), по правилам компании.
- **midroll** — вставка с прерыванием видео и со звуком, по расписанию компании.

| ID | Бренд | Тип | Правила |
|---|---|---|---|
| natria_vpn | NATRIA VPN | midroll (7.2 с, озвучка) | ровно по центру экрана, ≥25% площади; ролик < 2:00 — 1 раз ровно в середине; ≥ 2:00 — на 0:30 и 1:30; ускорение ≤ 1.3x; озвучка должна быть хорошо слышна |

Вставка: `python3 tools/ads.py <clip.mp4> <ad_id> <out.mp4>`
